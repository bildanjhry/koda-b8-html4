# Form Survey Perokok

### Mini-task html4 terkait form yang meniru terhadap google form dan tampilkan di Table.

Penggunaan layout CSS pada task ini cenderung menggunakan flexbox dengan beberapa properties meliputi:
- flex-direction 
- gap 
- justify-content 
- align-items 
- justify-self
